# Проект по БД

Проект получает 
данные о компаниях и вакансиях с сайта hh.ru,
загружает полученные данные в БД PostgreSQL и
позволяет работать с ними.  
Проект создан в учебных целях. В разработке.

## Технологии
[Python] (https://www.python.org/)
![Poetry](https://img.shields.io/badge/Poetry-%233B82F6.svg?style=for-the-badge&logo=poetry&logoColor=0B3D8D)

## Использование
Открыть проект в PyCharm.  
**api.py** содержит 2 функции:

`get_employer_id`  
Функция для получения ID работодателя.  
В config есть список интересующих работодателей,
функция определяет ID компаний на сайте hh.ru.  

`get_vacancies`  
Функция для получения вакансий по ID работодателя.  
Запрашивает вакансии с сайта hh.ru по ID работодателя.
В учебных целях стоит ограничение на выдачу 20 вакансий.

**data.py** содержит 5 функций:

`connect_to_db`
Функция подключения к базе PostgreeSQL

`create_tables`
Функция создает таблицы PostgreSQL  

`save_employers`
Заполняется таблица
employers - таблица с информацией о работодателях и их ID на сайте 
значениями с сайта hh.ru.

`save_vacancies`
Заполняется таблица
vacancies - таблица с информацией о вакансиях с их ID  и ID работодателя на сайте 
значениями с сайта hh.ru.

`fill_table`  
Функция создает таблицы PostgreSQL и заполняет их значениями
с сайта hh.ru. 
Создаются и заполняются 2 таблицы:
employers - таблица с информацией о работодателях с их ID на сайте
vacancies - таблица с информацией о вакансиях с их ID  и ID работодателя на сайте.  
Использует остальные 4 функции.

*dbm.py* содержит 1 класс:

`DBManager`    
Класс DBManager подключается к БД 
PostgreSQL и имеет следующие методы:

get_companies_and_vacancies_count()
 — получает список всех компаний и количество вакансий у каждой компании.  
get_all_vacancies()
 — получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.  
get_avg_salary()
 — получает среднюю зарплату по вакансиям.  
get_vacancies_with_higher_salary()
 — получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.  
get_vacancies_with_keyword()
 — получает список всех вакансий, в названии которых содержатся переданные в метод слова, например "python".  
Класс DBManager использует библиотеку psycopg2 для работы с БД.
